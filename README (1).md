## 🌟 Featured Projects

### 🏧 ATM Simulator
A console-based ATM built using **classes, methods and the constructor**.

```text
hi, how can I help you?
1. create pin
2. change pin
3. check balance
4. withdraw money
5. exit
```

**Concepts used:** OOP, `__init__`, methods, conditionals, user input.

### 🏠 Expiry Alert System
Never throw away expired food again! The script compares each item's expiry date with today's date and prints a status:

| Status | Meaning |
|--------|---------|
| ⚠️ **Alert** | Expires within 3 days |
| ❌ **Expired** | Already expired |
| ✅ **Safe** | Still fine to use |

**Concepts used:** Pandas DataFrame, `iterrows()`, `datetime`, f-strings.
